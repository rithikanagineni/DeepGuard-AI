PROJECT METHODOLOGY

Inside the DeepGuard AI Detection Engine

DeepGuard combines computer vision, deep learning feature extraction and classical machine learning to analyze facial media and classify it as Real or Fake.

Computer Vision MobileNetV2 CNN Features RBF SVM OpenCV
END-TO-END PIPELINE

From raw media to forensic screening

01

Data Collection

Real and manipulated video samples are collected for model development and testing.

02

Preprocessing

Frames are sampled, faces are detected, resized to 224×224 and normalized.

03

Feature Extraction

MobileNetV2 converts facial regions into 1280-dimensional visual representations.

04

SVM Classification

An RBF-kernel SVM evaluates extracted features for Real/Fake classification.

05

Final Decision

Frame-level evidence is aggregated to produce the video-level prediction.

TECHNICAL BREAKDOWN

What happens inside each stage?

01

Media Preprocessing

Videos are sampled at evenly distributed positions. A Haar Cascade face detector identifies facial regions. The largest detected face is selected, resized to 224×224 pixels and normalized for neural-network processing.

OpenCV Haar Cascade 224 × 224 Normalization
02

CNN Feature Extraction

A pretrained MobileNetV2 backbone is used as the visual feature extractor. Instead of directly using its final classification layer, the system produces a compact 1280-dimensional feature representation for each processed face.

MobileNetV2 TensorFlow / Keras 1280 Features Transfer Learning
03

SVM Classification

The extracted CNN representations are passed into an RBF-kernel Support Vector Machine. The classifier learns a decision boundary between real and manipulated facial media.

Scikit-learn RBF Kernel Binary Classification CNN + SVM
04

Video-Level Analysis

For video inputs, multiple frames are analyzed independently. Facial detections and frame-level predictions are aggregated to produce the final video-level Real/Fake result.

20 Frames Face-Aware Sampling Frame Aggregation Video Decision
